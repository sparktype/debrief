# Chorus Speak

Run `chorus speak --text <text> --voice <F1-F5|M1-M5> --speed <0.7-2.0> --volume <0-1>`. All four values are required and must be selected by the agent. Use the configured agent-role voice mapping unless the current task requires a deliberate override.
