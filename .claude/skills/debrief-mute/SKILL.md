# debrief:mute — 음소거 안내

음소거는 `debrief mute`로 토글합니다. `debrief mute on`과 `debrief mute off`로 지정합니다.

- 설정 파일은 직접 고치지 않습니다.
- 음소거 중에는 MCP `speak` 요청이 큐에 들어와도 재생되지 않습니다.
- 도우미 음성은 `debrief companion on|off`입니다.
