# chorus-digest skill
# 세션 발화 히스토리를 요약해 다이제스트로 출력하는 슬래시 커맨드

## 개요

`/chorus:digest` 슬래시 커맨드는 현재 세션의 최근 TTS 발화 히스토리를 분석해 세션 요약 다이제스트를 생성합니다. Claude Code hook 없이 독립 CLI로 실행됩니다.

## 트리거

다음 중 하나일 때 이 스킬을 사용합니다.

- 사용자가 `/chorus:digest`를 입력한 경우
- "세션 요약", "오늘 작업 요약", "다이제스트 들려줘" 등을 요청한 경우

## 실행 방법

```bash
python -m hook_voice digest            # 최근 10개 발화 기준
python -m hook_voice digest --last 20  # 최근 20개 발화 기준
```

## 출력 형식

LLM이 성공하면 다음 4가지 항목을 한국어 경어체로 출력합니다.

1. 완료된 작업
2. 미해결 블로커
3. 실패한 체크
4. 권장 다음 단계

히스토리가 없으면 "세션 히스토리가 없습니다." 메시지를 출력합니다.

## TTS 동작

- `autoSpeak=true`이면 reviewer 목소리(M2 빌)로 다이제스트를 읽어줍니다.
- LLM 실패 시 텍스트 요약만 출력하고 TTS는 생략합니다.
- 히스토리 없음 메시지는 기본 목소리로 짧게 읽어줍니다.
