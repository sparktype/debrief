# 영어 듣기 모드 결정 기록

- 목적(사용자): 회화 공부를 따로 하는 게 아니라 에이전트 사용 중 영어 듣기에 익숙해지기. 입력은 외부 앱으로 영어 입력 예정.
- 사용자 결정: 고정 알림도 영어로. 빠르기는 사용자가 고른다. 구현은 서브에이전트 병렬.
- 내 결정: `DebriefMode`에 넣지 않고 별도 불리언. quiet·night·dnd와 함께 켤 수 있어야 하기 때문.
- 내 결정: 언어 태그는 모드와 무관하게 텍스트로 판정(한글 포함 → ko, 아니면 en). 백엔드 트레이트에 언어를 흘리지 않아도 되고, 영어 모드가 아니어도 순수 영어 문장이 바르게 읽힌다.
- 내 결정: 빠르기는 데몬이 재생 시 덮어쓴다. 에이전트가 보낸 speed를 믿지 않아야 사용자가 고른 값이 확실히 지켜진다. 범위는 엔진 검증과 같은 0.7–2.0.
- 내 결정: 영어 모드에서는 발음 사전 전체를 건너뛴다. 기본 항목이 한글 표기(디브리프 등)라 섞이면 ko로 판정돼 영어 발음이 깨진다.
- 한계: Grok은 훅 출력을 버리므로 영어 브리핑 지침이 가지 않는다. 사용자가 영어로 입력하면 "사용자 언어" 규칙으로 영어가 된다.
