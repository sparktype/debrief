3. 개선 방향 비교

방식정확도추가 지연구현 난이도권장
A. 규칙 패턴 확장 ~60% 없음 낮음 —
B. LLM 동시 생성 (권장) ~90%+ 없음 (기존 LLM 호출 통합) 낮음 ✅
C. 별도 LLM 감정 분석 ~90%+ +100~200ms 낮음 —
B 방식이 최적: extract_one_liner()가 이미 LLM을 호출하므로, 같은 호출에서 감정 태그까지 함께 생성하면 추가 지연 없이 정확도 3배 향상. LLM 실패 시 현재 규칙 기반으로 자동 폴백.

4. B 방식 — LLM 기반 구현 설계

4-1. summarizer.py — extract_one_liner_with_tag 신규 함수

# hook_voice/summarizer.py — LLM 기반 감정 분석 방식

_ONE_LINER_WITH_TAG_SYSTEM = """
당신은 개발 작업 결과를 분석하는 AI입니다.
주어진 텍스트를 분석해 다음 두 가지를 JSON으로 반환하세요.

1. one_liner: 핵심 결과를 20자 이내 경어체 한 문장으로 요약
2. tag: 감정 표현 태그 — 아래 10개 중 하나만 선택
   - laugh : 성공·완료·칭찬·개선·긍정적 결과
   - sigh  : 실패·오류·에러·부정적 결과
   - hmm   : 분석 중·발견·탐색·생각 중
   - gasp  : 예상치 못한 발견·놀람
   - cry   : 치명적 장애·시스템 다운
   - sniff : 아쉬움·미완성·개선 필요
   - clear_throat : 경고·주의·중요 공지
   - yawn  : 반복적 정상 상태
   - cough : 경미한 주의 사항
   - breath: 일반 상황 (위 중 해당 없음)

반드시 JSON만 반환: {"one_liner": "...", "tag": "laugh"}
"""

async def extract_one_liner_with_tag(
    text: str, category: str, model: str = DEFAULT_MODEL
) -> tuple[str, str]:
    """LLM으로 한 줄 요약 + 감정 태그를 동시에 생성한다."""
    import json
    if not text.strip():
        return "", _ROLE_DEFAULT_TAGS.get(category, "<breath>").strip("<>")
    try:
        result = await chat_completion(
            messages=[
                {"role": "system", "content": _ONE_LINER_WITH_TAG_SYSTEM},
                {"role": "user", "content": strip_markdown(text)[:2000]},
            ],
            model=model,
            max_completion_tokens=80,
            temperature=0.0,
        )
        if result:
            data = json.loads(result.strip())
            one_liner = sanitize_for_speech(data.get("one_liner", ""))
            tag_name  = data.get("tag", "breath")
            VALID = {"breath","laugh","sigh","clear_throat","hmm",
                     "cough","sniff","gasp","yawn","cry"}
            tag = f"<{tag_name}>" if tag_name in VALID else "<breath>"
            return one_liner, tag
    except Exception:
        pass
    # 폴백: 기존 방식
    one_liner = sanitize_for_speech(_fallback(text, 1))
    return one_liner, select_expression_tag(one_liner, category)
