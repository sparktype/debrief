1. 문제 정의

현상: ko-KR-SunHiNeural / ko-KR-InJoonNeural 같은 단일언어(monolingual) 한국어 음성은 텍스트 내 영어 단어를 한국식 발음으로 읽는다.

예: "Kafka consumer group을 확인하세요" → "카프카 컨슈머 그룹을 확인하세요" (영단어 각각을 한글 발음으로 처리)

원하는 결과: 영어 단어는 영어 음소로, 한국어 구간은 한국어 음소로 자연스럽게 전환 (code-switching)

2. EdgeTTS 내부 구조 분석

edge_tts Python 라이브러리 소스 코드를 분석한 결과, 텍스트는 다음 파이프라인을 거친다:

text (str) → remove_incompatible_characters() # 비호환 유니코드 제거 → escape() # XML 특수문자 이스케이프 (&, <, >, ") → split_text_by_byte_length(4096) # 4096 바이트 단위 청크 분할 → self.texts: List[str] self.texts[i] → mkssml(tts_config, text) # SSML 래핑 → "{text}" → WebSocket 전송 → MP3 스트림 수신

문제 escape()가 텍스트 전체를 XML 이스케이프하므로, text 파라미터에 SSML <lang> 태그를 직접 삽입하면 &lt;lang&gt;로 이스케이프되어 음성 서버에 리터럴 문자열로 전달됨.

3. Microsoft Edge TTS에서 지원하는 SSML 구조

Microsoft TTS 서버가 실제로 수신하는 SSML (mkssml 결과):

<speak version='1.0' xmlns='http://www.w3.org/2001/10/synthesis' xml:lang='en-US'>
  <voice name='ko-KR-HyunsuMultilingualNeural'>
    <prosody pitch='+0Hz' rate='+0%' volume='+0%'>
      한국어 텍스트와
      <lang xml:lang="en-US">English words</lang>
      혼합 가능
    </prosody>
  </voice>
</speak>

<lang xml:lang="..."> 태그는 Multilingual Neural 음성에서만 동작한다. 단일언어 음성(SunHiNeural, InJoonNeural)은 무시.

6. 권장 구현: 방법 B — SSMLAwareCommunicate

핵심 원리: Communicate.__init__()가 설정한 self.texts를 초기화 직후 lang 태그가 삽입된 pre-built 내용으로 교체한다. mkssml()은 self.texts[i]를 그대로 SSML body에 삽입하므로, lang 태그가 이스케이프 없이 전달된다. 
import re
import xml.sax.saxutils as saxutils
import edge_tts
from edge_tts.communicate import split_text_by_byte_length, remove_incompatible_characters

# 영어 세그먼트 감지 패턴 (연속 ASCII 단어, 약어, 버전번호 포함)
_EN_PATTERN = re.compile(r'([A-Za-z][A-Za-z0-9\-_.]*(?:\s+[A-Za-z][A-Za-z0-9\-_.]*)*)')

def _build_mixed_ssml_body(text: str) -> str:
    """한영 혼합 텍스트를 SSML lang 태그가 포함된 inner body로 변환."""
    parts: list[str] = []
    last = 0
    for m in _EN_PATTERN.finditer(text):
        # 앞 한국어 구간
        ko_chunk = text[last:m.start()]
        if ko_chunk:
            parts.append(saxutils.escape(ko_chunk))
        # 영어 구간 → lang 태그로 감싸기
        en_chunk = m.group()
        parts.append(f'{saxutils.escape(en_chunk)}')
        last = m.end()
    # 나머지 한국어
    if last < len(text):
        parts.append(saxutils.escape(text[last:]))
    return ''.join(parts)


class SSMLAwareCommunicate(edge_tts.Communicate):
    """한영 혼합 텍스트에서 영어 구간에 lang 태그를 주입하는 Communicate 확장."""

    def __init__(self, text: str, voice: str, **kwargs):
        # 더미 텍스트로 부모 초기화 (에러 방지)
        super().__init__(".", voice, **kwargs)
        # self.texts를 lang 태그 포함 SSML body로 교체
        ssml_body = _build_mixed_ssml_body(text)
        self.texts = split_text_by_byte_length(
            remove_incompatible_characters(ssml_body).encode("utf-8"),
            4096,
        )

7. 음성 매핑 수정 방향

핵심: <lang> 태그는 ko-KR-HyunsuMultilingualNeural에서만 동작한다. 기존 SunHiNeural/InJoonNeural은 Multilingual 음성으로 교체 또는 병행 운영이 필요하다.

현재 스피커현재 음성제안
Sohee, Vivian, Serena, Uncle_Fu, Ono_Annako-KR-SunHiNeural→ ko-KR-HyunsuMultilingualNeural (성별 차이 감수)
또는 영어 구간은 en-US-AvaMultilingualNeural로 별도 처리
Ryan, Eric, Dylanko-KR-InJoonNeural
Aidenko-KR-HyunsuMultilingualNeural이미 최적 — lang 태그 즉시 적용 가능

* 여성 멀티링구얼 한국어 음성은 현재 Microsoft에서 미제공. 여성 음성이 필요하면 en-US-AvaMultilingualNeural(영어 기반, 한국어 혼용 가능)을 검토.

결론

단기: 모든 음성을 ko-KR-HyunsuMultilingualNeural로 통일 → 자동 감지로 영어 발음 즉시 개선.
권장: MixedComm 서브클래스로 영어 구간에 <lang xml:lang="en-US"> 태그 명시 삽입 → 가장 자연스러운 코드스위칭.
여성 음성 문제: Microsoft에 ko-KR 여성 Multilingual 음성이 없으므로, 여성 음성이 중요하면 en-US-AvaMultilingualNeural을 한국어 기본 음성으로 설정하는 역발상도 고려.
