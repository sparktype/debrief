1. 현황 분석

현재 구성
Supertonic 3 ONNX Runtime 44.1kHz WAV 99M 파라미터 한국어(ko) 지원 10개 내장 목소리 (F1-F5, M1-M5)

현재 프로젝트는 supertonic serve로 띄운 서버의 OpenAI 호환 엔드포인트 (/v1/audio/speech)만 사용합니다. 이 엔드포인트는 voice, speed, lang 세 파라미터만 노출하며, 가장 중요한 품질 파라미터 steps가 빠져 있습니다.

핵심 문제
/v1/audio/speech는 steps를 지원하지 않아 항상 기본값(8)으로 생성됩니다. Native API /v1/tts로 전환하면 12까지 올려 품질을 즉시 높일 수 있습니다.

두 API 비교

파라미터/v1/audio/speech (OpenAI compat)/v1/tts (Native)
steps❌ 미지원✅ 1–100 (기본 8)
speed✅ 0.7–2.0✅ 0.7–2.0
lang✅✅
max_chunk_length❌✅ 긴 텍스트 분할 제어
silence_duration❌✅ 문장 간 묵음 길이
response_format제한적wav / flac / ogg

2. Supertonic 품질 개선 방법

방법 A: steps 파라미터 올리기 (가장 즉각적인 효과)

Supertonic 3은 diffusion 계열 아키텍처로 steps가 품질을 직접 결정합니다.

steps 값품질속도권장 용도
5저가장 빠름미리보기
8 (현재 기본값)중빠름일반 알림 TTS
10–12고약간 느림에이전트 발화, 중요 알림
15+최고느림음성 샘플링·테스트
적용 방법 — tts_server/server.py 수정
현재 /v1/audio/speech를 /v1/tts로 교체하고 steps 파라미터를 추가합니다. 
# hook_voice/player.py — speak_agent() 내부 변경 전
payload = {
    "model": "supertonic-3",
    "input": text,
    "voice": voice,
    "speed": speed,
    "lang": "ko",
    "response_format": "wav",
}
resp = await client.post("http://localhost:7788/v1/audio/speech", json=payload)

# ── 변경 후: Native /v1/tts 사용 + steps=12 ──
payload = {
    "text": text,
    "voice": voice,
    "speed": speed,
    "lang": "ko",
    "steps": 12,           # 8→12: 품질 향상 (속도 약 50% 증가)
    "silence_duration": 0.1,
    "response_format": "wav",
}
resp = await client.post("http://localhost:7788/v1/tts", json=payload)

방법 B: Expression Tags로 자연스러운 발화

Supertonic 3은 10개 인라인 태그를 지원합니다. 적절한 위치에 삽입하면 기계적 발화를 크게 줄일 수 있습니다.

태그효과예시
<breath>자연스러운 호흡알림 시작 전 삽입
<laugh>가벼운 웃음긍정 결과 뒤
<sigh>한숨오류 상황
<clear_throat>헛기침, 집중 유도중요 알림 앞
<hmm>생각하는 뉘앙스분석 결과 앞
# sanitize_for_speech 수정 없이 _speak_agent 내부에서 태그 삽입
def _add_expression(text: str) -> str:
    return f"<breath> {text}"

# 예: "리뷰어 빌입니다. 코드 품질에 문제가 있습니다."
# → "<breath> 리뷰어 빌입니다. 코드 품질에 문제가 있습니다."
주의
Expression Tags는 sanitize_for_speech()에서 제거되지 않도록 예외 처리 필요. 현재 코드는 특수문자·꺾쇠를 제거하므로 태그가 지워집니다.

방법 C: Voice Builder로 커스텀 목소리 추가

Supertonic Voice Builder (supertonic.supertone.ai/voice-builder)에서 실제 목소리 샘플을 업로드하면 커스텀 JSON을 생성해줍니다. 이를 /v1/styles/import로 임포트하면 내장 F1–M5 외의 추가 목소리를 사용할 수 있습니다.

# 커스텀 스타일 임포트
curl -X POST http://localhost:7788/v1/styles/import \
  -F "file=@my_voice.json" \
  -F "name=custom_park"

# 사용
curl -X POST http://localhost:7788/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"안녕하세요","voice":"custom_park","lang":"ko","steps":12}'

방법 D: 오디오 후처리 (즉각 적용 가능)

현재 afplay -r <speed>로만 후처리 중입니다. ffmpeg를 추가하면 EQ·정규화로 체감 품질을 개선할 수 있습니다.

# 고역 강조 + 볼륨 정규화 (ffmpeg 사용)
ffmpeg -i input.wav \
  -af "equalizer=f=3000:width_type=o:width=2:g=3, loudnorm=I=-14:LRA=7:TP=-1" \
  -ar 44100 output.wav

3. 한국어 지원 대안 모델 (mlx-audio 기반)

mlx-audio v0.4.3에서 한국어를 명시 지원하는 모델들입니다. 모두 Apple Silicon MLX로 가속됩니다.

🔊 Supertonic 3 (현재)

Supertone · ONNX Runtime · 99M 파라미터 · 44.1kHz

ONNX 기반 초경량 모델. 31개 언어, 10개 내장 목소리. 실시간 합성 가능. steps로 품질/속도 트레이드오프 조절.

한국어 ✓ 초고속 중간 품질

⭐ Qwen3-TTS (최우선 검토)

Alibaba · MLX · 0.6B / 1.7B · ZH·EN·JA·KO

한국어 네이티브 지원. 음성 복제(VoiceCloning), 감정 제어, VoiceDesign 기능 내장. 8bit 양자화로 메모리 효율도 높음.

한국어 ✓ MLX 가속 음성 복제

🎙️ Chatterbox

Resemble AI · MLX fp16 · 한국어 포함 16개 언어

표현력이 풍부한 다국어 TTS. 한국어를 공식 지원 언어 목록에 포함. 음성 복제 기능 포함.

한국어 ✓ MLX 가속 fp16 (대용량)

🧠 Higgs Audio v2

Boson AI · MLX · 3B · Llama 기반 · EN·ZH·KO·DE·ES

Llama 백본의 대형 TTS. 실시간 음성 복제 지원. 한국어 포함 5개 언어. q8/q6 양자화 제공.

한국어 ✓ 실시간 클로닝 3B (느림)

🌿 MOSS-TTS

OpenMOSS · MLX · 8B/1.7B/100M · 20개 언어

한국어 포함 20개 언어 지원. Nano(100M) 버전은 초경량. delay-pattern 아키텍처로 자연스러운 운율 생성.

한국어 ✓ Nano 100M 20개 언어

❌ Kokoro

MLX · 82M · EN·JA·ZH·FR·ES·IT·PT·HI

초경량 고품질 TTS이지만 한국어 미지원. 영어·일본어에서는 Supertonic 대비 우수한 자연스러움을 보임.

한국어 ✗ 초경량 82M 영어 품질 최고

5. 권장 방향

즉시 적용 가능 (코드 최소 변경)
Supertonic + Native API 전환 + steps=12
player.py에서 /v1/audio/speech를 /v1/tts로 바꾸고 "steps": 12 추가. 1–2시간 작업, 즉각적인 품질 향상.
중기 개선 (1주일)
Qwen3-TTS 0.6B 병행 운영
mlx-audio의 Qwen3-TTS를 별도 엔드포인트로 띄우고, 에이전트 발화처럼 "품질 우선" 케이스에 선택적으로 사용. 한국어 자연스러움이 Supertonic보다 높고 메모리도 합리적 (~600MB at 8bit).
장기 검토
Higgs Audio v2 (3B) 또는 Chatterbox
음성 복제까지 필요하다면 Higgs Audio v2. 다만 3B 모델이므로 M1 16GB에서 응답 지연이 생길 수 있음. 실제 측정 필요.

단계별 실행 계획

  1. Supertonic Native API 전환 — player.py 수정, steps 파라미터 voice-map.json에 role별로 추가 (리뷰어=12, 빌더=8 등)
  2. Expression Tags 활용 — sanitize_for_speech()에서 Supertonic 태그 예외 처리, hook_handlers에서 문맥별 태그 삽입
  3. Qwen3-TTS 0.6B 실험 — mlx-audio로 별도 포트(7789) 서빙, player.py에 엔진 선택 파라미터 추가
  4. Voice Builder 커스텀 목소리 — 실제 목소리 녹음 → supertonic.supertone.ai/voice-builder → JSON 임포트
