📋 조사 방법

설치된 mlx-audio 패키지 소스코드 직접 분석 + 지식 기반. HuggingFace 웹 검색은 내부 게이트웨이 제한으로 불가. 로컬 캐시에는 현재 모델(Qwen3-TTS CustomVoice)만 존재.

권장 다음 단계

① Chatterbox 즉시 테스트 (mlx-audio 지원, 설치 불필요)

# HuggingFace에서 모델 다운로드 후 테스트
python3 -m mlx_audio.tts.generate \
  --model resemble-ai/chatterbox \
  --text "안녕하세요, Chatterbox로 한국어 TTS를 테스트합니다." \
  --lang_code ko \
  --play

② MeloTTS 속도 테스트 (mlx-audio 지원)

# KR 스피커로 빠른 생성 테스트
python3 -m mlx_audio.tts.generate \
  --model myshell-ai/MeloTTS \
  --text "한국어 TTS 속도 테스트입니다." \
  --lang_code KR \
  --play

③ Edge TTS 클라우드 폴백 검토 (품질 최상)

pip install edge-tts
# 한국어 목소리: ko-KR-NanaNeural, ko-KR-SunHiNeural, ko-KR-InJoonNeural
edge-tts --voice ko-KR-NanaNeural --text "마이크로소프트 에지 TTS 테스트" --write-media test.mp3
afplay test.mp3

💡 결론 요약

  • 현재 Qwen3-TTS는 한국어 전용 스피커 + instruct 제어로 siren-mcp 용도에 적합한 선택
  • Chatterbox는 2025년 최신 모델로 한국어 품질이 더 자연스러울 가능성 높음, 바로 테스트 권장
  • MeloTTS는 속도가 압도적으로 빠르므로 RTF 개선이 필요할 때 유용
  • Edge TTS는 네트워크 의존이지만 품질 최상, 오프라인 불가시 클라우드 폴백으로 검토 가능
  • Kokoro는 한국어 미지원으로 제외
