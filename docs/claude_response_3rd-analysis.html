아키텍처·신뢰성 — 구조적 개선점

HIGHHTTP vs Spool 이중 재생 경로 — 동시 발화 가능
player.py:95-96, supervisor.py player_loop

speak_hook의 spool 경로와 _speak_http의 서버 직접 재생 경로가 분리되어, 폴백 발생 시 두 afplay가 동시에 실행될 수 있다. save_last_message 호출 위치도 불일치.

spool을 단일 재생 경로로 통일. HTTP /speak 엔드포인트는 spool 기록 API로 변경하거나 제거.

HIGHSupervisor 전체 재시작 전략 — 가용성 손실
supervisor.py monitor_children

supertonic 하나가 죽으면 정상 동작 중인 uvicorn까지 내려간다. 모델 재로딩 시간 동안 EdgeTTS 폴백도 불가.

자식별 독립 재시작 카운터 추가. N회 실패 시에만 supervisor 전체 종료.

HIGHConfig timeout 값들이 실제 코드에서 무시됨
player.py:53, 105, 128 — timeout 하드코딩

edge_timeout_ms·supertonic_timeout_ms를 .voice-persona.json에서 설정해도 player.py의 하드코딩된 10.0/20.0/0.5초에 전혀 반영되지 않는다.

speak_hook/speak_agent에 config를 전달하고, 모든 timeout을 config 값으로 교체.

MEDIUM_ec._SSL_CTX 모듈 레벨 패치 — 버전 업그레이드 시 조용히 깨짐
player.py:19-22

edge_tts 내부 구현 변경 시 _SSL_CTX 속성이 사라져 AttributeError. hasattr 가드 없음.

hasattr 확인 후 패치. 장기적으로 HMG CA를 신뢰 번들에 추가하는 방향으로 이행.

MEDIUM_FALLBACK_MAP voice_names.F1 = "멜린다" — voice-map.json과 불일치
voice_router.py:34

최근 커밋에서 연아로 변경됐으나 코드 내 폴백값은 멜린다 그대로. voice-map.json 로드 실패 시 다른 이름으로 발화.

_FALLBACK_MAP의 F1을 "연아"로 동기화.

MEDIUM확장성 — hook 추가 시 5개 파일 동시 수정 필요
__main__.py, hook_handlers.py, hooks/, server.sh install/uninstall

새 hook 타입 추가 시 모든 파일을 동시에 건드려야 한다. TTS 엔진도 player.py에 모두 하드코딩.

server.sh의 hook 등록을 HOOKS 배열+루프로 리팩터. _TECH_PHONETICS를 phonetics.json으로 분리.

quality-analyst

코드품질·테스트 — 12개 이슈

HIGH전 폴백 체인에서 Exception을 로그 없이 삼킴
player.py:95-96, hook_handlers.py:44, voice_router.py:48

except Exception: pass 패턴이 반복되어 운영 중 어떤 경로가 실패했는지 추적 불가. 장기 기술부채.

최소한 logging.debug 또는 logging.warning으로 실패 원인 기록.

HIGHasyncio.get_event_loop() 사용 — Python 3.12에서 RuntimeError
__main__.py:20

asyncio.run() 내부에서 get_event_loop() 대신 get_running_loop() 사용해야 함. 3.12+에서 RuntimeError.

loop = asyncio.get_running_loop() 로 교체.

HIGHVoiceMap TypedDict 선언과 검증 불일치
voice_router.py:22-28, load_voice_map:45

TypedDict 필수 필드로 선언한 voice_names·instructs를 유효성 검사에서 확인하지 않아 타입 선언이 거짓말을 함.

load_voice_map 검증에 voice_names·instructs 포함, 또는 TypedDict를 Optional 필드로 변경.

HIGHhandle_subagent_stop agent_type="" 시 무음 처리
hook_handlers.py:126-145

agent_type 인식 실패 시 조용히 default로 폴백. 에이전트 타입 인식 실패인지 의도적 default인지 구분 불가.

복구 실패 시 logging.warning("agent_type 인식 실패, default 사용") 추가.

MEDIUMtranscript 파일 전체 메모리 로드
hook_handlers.py:29, skill_recommender.py:88

장기 세션에서 수십 MB JSONL을 전체 읽은 뒤 splitlines()[-N] 적용. 불필요한 메모리 피크.

역방향 readline 방식으로 교체. 마지막 N줄만 읽기.

MEDIUMhandle_subagent_stop 테스트 전무
tests/test_hook_handlers.py

agent_type 없는 경우, extract_one_liner 빈 반환, speak_agent 폴백 경로 등 핵심 분기 미검증.

handle_subagent_stop 파라미터화 테스트 추가. transcript 복구 경로 포함.

MEDIUM_transcript_cache가 프로세스 내에서만 유효
skill_recommender.py:14

hook_voice는 매 호출마다 새 프로세스로 실행. 모듈 레벨 캐시는 실제 캐시 효과 0. 코드가 오해를 유발.

캐시 제거 또는 주석으로 "현재 프로세스 수명 내 캐시" 명시.

성능·보안·안정성 분석

perf-analyst

성능·보안·안정성 — 10개 이슈

CRITICAL전역 SSL 검증 비활성화
player.py:19-22, llm_client.py:25-28

edge_tts 모듈 전체에 CERT_NONE 적용 + httpx verify=False. MITM으로 TTS 응답 조작 또는 LLM API 응답 위조 가능.

HMG CA PEM을 신뢰 번들에 추가. httpx는 verify=hmg_ca_pem_path 사용.

HIGHtempfile.mktemp() TOCTOU 취약점
player.py:45, 141

mktemp()는 경로 반환만 하고 파일을 생성하지 않아 TOCTOU. 공격자가 심볼릭 링크 삽입 가능.

tempfile.NamedTemporaryFile(delete=False, suffix=".mp3")으로 전환.

HIGHspool Race Condition — meta 없이 오디오 파일만 있는 상태
supervisor.py:64-84, player.py:36-41

_enqueue_spool에서 rename 후 meta write 사이 비원자성. Player가 meta 없는 파일을 읽으면 config tts_speed 무시하고 기본값 1.2 적용.

파일명에 speed 인코딩: {uid}_{speed}.wav. meta 파일 제거.

HIGH모듈 레벨 asyncio.Event — 테스트 격리 문제
supervisor.py:20

_shutdown_event가 모듈 임포트 시 생성. asyncio.run() 여러 번 호출 시 이벤트 루프 교체로 shutdown 전달 실패.

main() 내부에서 asyncio.Event() 생성 후 명시적으로 각 코루틴에 전달.

MEDIUMstop.sh stdin payload 미전달
hooks/stop.sh:5

subagent-stop.sh는 PAYLOAD=$(cat)로 보존하는데 stop.sh만 누락. handle_hook이 빈 raw로 폴백해 추가 파일 I/O 발생.

PAYLOAD=$(cat) + echo "$PAYLOAD" | nohup ... 추가.

MEDIUMAPI 키 누락 시 무음 처리 — 인증 없이 요청 전송
llm_client.py:10-11

HUB_API_KEY 미설정 시 "Bearer " 빈값으로 요청. 오류 로그 없어 개발자가 인지 불가.

api_key 비어있으면 logging.warning 후 조기 반환.

MEDIUMafplay terminate 후 proc.wait() 없어 좀비 프로세스 위험
supervisor.py:80-84

proc.terminate() 후 바로 audio.unlink(). 명시적 wait 없어 좀비 프로세스 남을 수 있음.

terminate 후 asyncio.wait_for(proc.wait(), timeout=2.0) 추가. 타임아웃 시 kill().

P3 — 중기프로젝트별 voice persona 자동 전환

CLAUDE_PROJECT_DIR 기반으로 프로젝트별 .voice-persona.json 우선 적용

P3 — 중기에이전트 발화 포맷 개선 — 성공/경고 분기

현재: "{label} {name}입니다. {one_liner}" 고정 패턴으로 반복 청취 피로도 높음
